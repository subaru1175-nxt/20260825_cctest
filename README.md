# 暗記CARD

英単語の「コアイメージ」と「自然な使い方」を、フラッシュカードで覚える学習アプリです。
日本語訳の丸暗記ではなく、**英語の音 → 場面・感覚 → 使い方** の順に思い出す練習をします。
毎日 **20:00 のテスト**と、満点になるまで続く**再テスト**、**5日ごとのまとめテスト**、**毎月1日の月のまとめテスト**で、長く覚えていられるようにします。

開くとタイトル（暗記CARD）が出て、画面をタップすると、セクションごとに分かれたホームに進みます。

### 毎日の順番（ホームの「今日の学習」）

| 手順 | すること |
| --- | --- |
| ① 単語を覚える | 英語 → 場面。新しい単語と、復習の時期の単語（今日の目標の枚数まで） |
| ② 逆から思い出す | 場面 → 英語。① で今日覚えた単語と、復習の時期の単語 |
| ③ ミスを確認 | 今日のカードで思い出せなかった・あいまいだった単語と、テストで間違えた問題を、正しい答え・音声と一緒に確かめる |
| ④ 間違えた問題を解く | ③ のミスを問題で練習（何度でも。記録には入らない） |
| ⑤ テスト（20:00 から） | 今日学習した単語のテストと、必須の再テスト |

いまやる手順に青いボタンが出ます。カード学習が終わると、結果の画面から次の手順に進めます。

### テストの時間割

- **毎日のテスト**：毎日 **20:00 から朝4:00まで**（時間は設定で 18:00〜22:00 に変えられます）。それ以外の時間は受けられません。
- **今日のテスト**：前のテストのあとに学習した単語（最大20語）を、内容理解（4択）と文章作成（並べ替え）で。100点満点。
- **再テスト（必須）**：テストで間違えた問題は、**次の日の 20:00** に必須の再テストになります（間違えたときと同じ形式）。また間違えたら、その次の日も。**満点になるまで毎日続きます。** その日のうちの正解（練習など）では「克服」にしません。
- **まとめテスト（5日ごと）**：使いはじめた日を1日目として、5日目・10日目…の 20:00 から。前の回のあとに学習した単語を、**応用の形式**（英文を聞いて意味を選ぶ・新しい文の空所・つづりを組み立てる・並べ替え）で。1語から「わかる」と「書ける」を1問ずつ（最大30問）。
- **月のまとめテスト（毎月1日）**：11/1・12/1・1/1… の 20:00 から、**先月に学習した単語**を応用の形式で約50問。
- 1日の区切りは**朝4:00**です（夜ふかしして 0:00〜4:00 に学習・テストしても、前の日の分として数えます）。

### 効果音とスコア

- タップ・カードをめくる・評価・正解／不正解・手順の完了・セットやテストの完了のときに、短い効果音が鳴ります（音のファイルは使わず、その場で作る短い音）。テストの4択は、選んだ単語の音が鳴り終わってから正解／不正解の音が鳴ります。設定 → 音声 →「効果音」でオフにできます。
- セットやテストが終わると、点数の輪と評価が出ます。5つの手順がすべて終わった日は、ホームに **今日のスコア**（学習した枚数・思い出せた割合・テストの点・ポイント）が出ます。

### 通知

ホーム画面のアプリやブラウザは、閉じているあいだ自分では通知を出せません（通知の仕組みにはサーバーが必要なため）。
そこで「設定 → テストの時間と通知」から、**カレンダーに通知つきの予定**（毎日のテスト・5日ごとのまとめテスト・毎月1日の月のまとめテスト）を入れられます。

- 「カレンダーに通知を追加」：.ics ファイルを保存 → 開いて追加（iPhone は「すべてを追加」）。テストの時刻に、端末のカレンダーから通知が届きます。
- 「Googleカレンダーに追加」：毎日・5日ごと・毎月1日の予定を、それぞれ Googleカレンダーの作成画面で追加できます。
- アプリを開いているときは、テストの時刻になると画面でもお知らせします。

スマホの縦画面向けに作った Web アプリで、ビルドやインストールは不要です。
デザインは、**ライトグレー**を基調に、大事なところだけメタリックブルーの光沢を使ったミニマルなものです（暗い画面の設定ではグラファイト）。
英語の音声は、あらかじめ作った **AI音声（アメリカ英語・やわらかい女性の声）** で、「ゆっくり」もはっきり遅く聞き取れます。テストで選択肢をタップすると、その瞬間に選択肢の単語の音が鳴ります。

## 操作の決まり

どの画面でも、同じ形の部品を同じ意味で使います。

| 部品 | 意味 |
| --- | --- |
| メタリックブルーのボタン | そのまとまりで、いちばん大事な操作（1つだけ）。例：カードで学習する・テストを受ける・裏を見る・次へ |
| 縁がメタリックブルーのボタン | もう一つの操作。例：もう1セット・わからない |
| › のある行 | 別の画面へ移る。赤い文字の行は、消す操作（確認してから実行） |
| 切り替え | 2〜3個から選ぶもの。例：英語 → 場面／場面 → 英語（選んだものは覚えておきます） |
| ［再生｜ゆっくり］ | 英語の音声。下の小さな文字が音声の種類（AI音声・アメリカ英語／録音（人の声）／端末の読み上げ）。再生中は押したボタンが光り、中の線が音の長さだけ進み、「ゆっくり再生中（ふつうの2.2倍・1.3秒）」のように表示します |

## 画面

- **タイトル**：「暗記CARD」のロゴと一言だけ。どこをタップしてもホームへ
- **ホーム**：上にロゴと日付、今日の目標・連続日数・ポイントを1行で。その下にセクション：**今日の学習**（①〜⑤ の手順。ふだんは名前と右の数だけで、いまやる手順にだけ一言と青いボタン）／**テスト**（受けられる時間と、再テスト（必須）・今日のテスト・まとめテスト・月のまとめテスト。右に問題の数や次の日付）／回（覚え具合の線と学習した数）／復習（覚えていないリスト）。途中のカード学習・テストがあるときは「途中から」も出ます
- **ホーム画面に追加**：iPhone のホーム画面に置く5つの手順と、アプリのリンク（コピーできる）
- **ミスを確認**（③）：テストで間違えた問題（正解・あなたの答え・再テストの日時）と、今日のカードで思い出せなかった単語（ニュアンス・例文）。どれも単語の音声つき
- **シリーズ**：学習中のシリーズ（このシリーズを学習する）、1 カードで覚える（切り替え＋「カードで学習する」）、2 シリーズのテスト（全範囲・受験回数・最高点・何回目で満点か＋「テストを受ける」。20:00 から）、テストの記録（回目ごとの点数）、この回の覚えていないリスト・単語の一覧
- **カード学習**：表面 → タップで裏面 → 3段階の自己評価。上部に進捗バーと残り枚数。演出は控えめにしています
- **学習結果**：思い出せた割合の輪（数え上げの動き）と評価（PERFECT・EXCELLENT・GREAT・GOOD・NICE TRY）、かかった時間、獲得ポイント、評価の内訳、次の手順へのボタン。次の復習日はたたんで表示、**次の手順へ進むボタン**
- **テスト**：内容理解（4択）→ 文章作成（並べ替え）。まとめテストでは、聞き取り・新しい文の空所・つづりも。**選択肢をタップした瞬間に、その選択肢の単語の音が鳴ります**（意味の選択肢は、その意味の英単語）。答えたあとも選択肢をタップすると単語が鳴り、意味の選択肢には英単語も出ます。正解の4択は、単語の音が鳴り終わってから次へ進みます。並べ替え・つづりは、答え合わせのときに正しい英文・単語を鳴らします
- **テストの結果**：点数の輪と評価、正解の数・かかった時間、内容理解と文章作成それぞれの点、満点まであと何点か・何回目で満点を取ったか、再テストの予定、間違えた問題の一覧（あなたの答えと正解）
- **覚えていないリスト（下のメニューの「復習リスト」）**：間違えた問題を回をまたいで一覧にし、再テストの日時を表示。カードで学習・練習ができます
- **単語一覧・詳細**：検索・絞り込み（復習待ち／要確認／未確認）。詳細では同じ単語の用法をグループごとにまとめて表示し、学習の記録・評価の履歴・出典と確認状況も出します
- **単語の追加・編集**：用法・例文・似た単語・発音・録音音声URLを追加・編集できます
- **設定**：テストの時間と通知（時間の変更・カレンダーに追加）、ホーム画面に追加する手順、音声（AI音声の説明と試し聞き・自動再生、たたんだ中に端末の読み上げの声と速さ）、今日の目標・発音記号の表示、データの書き出し・読み込み、リセット、このアプリについて

## カードのつくり

**1カード = 1つの意味・用法** です（例：`pretty` の「かわいい」と `pretty tired` の「けっこう」は別カード）。

- **表面**：英単語（大きく）、発音記号、音声（通常・ゆっくり）、用法を見分けるための短い英語フレーズ
- **裏面**（この順に表示）
  1. 一言ニュアンス（「〇〇って感じ」）
  2. 頭に浮かべる場面（身近な場面の文と、絵や図）
  3. 意味と、文の中での役割（「動き」「どんな（様子）」などの言葉と、動詞・形容詞などの名前）
  4. 自然な短い例文（英語と日本語訳を別の行に。音声は英語だけ）
  5. 「くわしく見る」を開くと：役割の説明、似た単語との違い、発音（米・英の発音記号、強く読む位置）、補足

意味が離れた用法（`well` の「上手に」と「井戸」、`light` の「光」と「軽い」など）は別のグループにしています。
**無理に一つのコアイメージにまとめません。** コアイメージは理解を助ける説明であり、すべてのネイティブスピーカーが同じイメージを持っているとは限りません。

## 学習のしくみ

1セットは基本10枚。出題の優先順は **復習予定日を過ぎたカード（遅れている順）→ 新しいカード → 予定が近いカード（前倒し）** です。
同じ単語のカードは、できるだけ続けて出さないようにしています。

| 自己評価 | セットの中 | 次の復習 |
| --- | --- | --- |
| ✕ 思い出せなかった | 3枚あとにもう一度（最大3回） | 10分後（同じ日にまた出る） |
| △ あいまい | 5枚あとにもう一度（1回） | 間隔を半分に（最短で翌日） |
| ○ 思い出せた | 出さない | 間隔を広げる（1日 → 3日 → 約8日 → 約20日 …） |

- 間隔を変えるのは、そのセットで**最初に答えたとき**だけです。再出題で思い出せても、間隔を2回伸ばしません。
- 予定日より前に解いて思い出せた場合も、間隔は伸ばしません。
- **1回答えられただけでは「定着」にしません。** 習得度は「未学習 → 覚えはじめ → 復習中 → 定着してきた」です。「定着してきた」は、間隔が21日以上で3回続けて思い出せたカードです。その後も復習は続きます。
- **場面 → 英語** の練習は、「英語 → 場面」で一度学習したカードから出ます。表面には場面・ニュアンス・穴あき例文が出ます（単語は隠し、ヒントで最初の文字を出せます）。復習予定は英語 → 場面とは別に記録します。
- ポイント：○ 10・△ 6・✕ 3（正直に評価しても損をしないように）、再出題 1、セット完了 +20、今日の目標達成 +30。
- 連続学習日数は、1枚でも学習した日が続いた日数です。
- 途中で ✕ を押して中断しても、回答ごとに保存しているので、ホームの「続きから再開」や再読み込みで同じカードから再開できます。

## シリーズとテスト

**シリーズ1** は手書きの単語リスト（Untitled_Notebook.pdf）の98語です。新しい単語のリストを Claude に送ると、**シリーズ2・シリーズ3…** として同じ形（辞書で確かめた意味・発音、場面、例文、テスト用の文、AI音声）で追加されます（アプリの「シリーズを追加」に案内があります。作り方は `data/notebook/README.md`）。

- **学習中のシリーズ**：毎日の ① の新しい単語は、このシリーズから出ます。選んでいなければ、覚え終わっていない最初のシリーズです。シリーズの画面の「このシリーズを学習する」で、先に次のシリーズを始めることもできます（復習の時期のカードは、どのシリーズでも出ます）。
- 前の版の「第1回」という名前は、自動で「シリーズ1」になります。
- 単語の編集画面で、自分で追加した単語をどのシリーズに入れるかも選べます。

### テスト（100点満点）

| 部 | 問題 | 配点 |
| --- | --- | --- |
| 内容理解 | 4択。用法ごとに1問。「意味を選ぶ」「場面から単語を選ぶ」「例文の空所」を、テストの回ごとに入れ替えて出します | 50点 |
| 文章作成（応用） | 日本語の意味になるように、単語を並べ替えて英文を作ります。**カードには出てこない新しい文**（テスト用の例文）を使います | 50点 |

- 点数は「内容理解の正解率 × 50」と「文章作成の正解率 × 50」の合計（小数は切り捨て）。全問正解のときだけ100点です。
- 1問答えるごとに、正解・不正解と正しい答えを表示します。文章作成では正しい英文の音声も聞けます。
- 途中でやめても、続きから再開できます（再読み込みしても同じ問題から）。内容理解と文章作成の間には区切りの画面があります。
- テストの記録は回ごとに「1回目・2回目…」と残り、**何回目で満点を取ったか**を回の画面・ホーム・結果画面に表示します。
- 回のテストも、毎日のテストと同じく 20:00 から朝4:00まで受けられます。間違えた問題は、次の日の再テスト（必須）に入ります。

### 覚えていないリスト

- テストで間違えた問題は、その場で「覚えていないリスト」に入ります（テストを最後までやらなくても残ります）。
- **すべての回の間違いが、ひとつのリストにたまっていきます。** 回ごとに絞り込むこともできます。
- 「カードで学習」で間違えた単語だけのカード学習、「問題を練習する」で間違えた問題だけの練習ができます（練習は記録に入りません）。
- 間違えた問題は、次の日の 20:00 からの**再テスト（必須）**に出ます。そこで正解すると「克服」、また間違えると、その次の日の再テストへ。満点になるまで続きます。**記録は消さず**、「克服した」「すべて」で振り返れます。何回まちがえたか、最後にまちがえた日も残ります。

## 音声

- 英語だけを読み上げます（日本語の説明は読み上げません）。
- 音声の種類は、ボタンの下の小さな文字で分かります。使う順番は次のとおりです。
  1. **録音（人の声）**：用法ごとに録音ファイルの URL を登録したとき
  2. **AI音声・アメリカ英語**：あらかじめ作った音声（`audio/*.mp3` と目録 `js/audio-pack.js`）。初期の単語のすべての単語・フレーズ・例文・テスト用の例文（586件）にあります
  3. **端末の読み上げ**：上の2つがない英語（自分で追加した単語など）
- **AI音声**：Kokoro-82M の `af_heart`（アメリカ英語・やわらかく聞き取りやすい女性の声）。発音は Kokoro の学習に使われたアメリカ英語の発音辞書で決めています。作り方・素材・ライセンスは [scripts/audio/README.md](scripts/audio/README.md)
- **ゆっくり**：ふつうの音声を、音の高さを変えずに引き伸ばした、本当に遅い音声です。長さはふつうの **1語で2.2倍、2〜4語で1.8倍、5語以上の文で1.6倍**。再生中は、ボタンの下に「ゆっくり再生中（ふつうの2.2倍・1.4秒）」のように出し、線が音の長さだけ進みます。
  1語は Praat の PSOLA（声の周期に合わせて引き伸ばす方法）、2語以上は WSOLA で作っています。音声認識での聞き取りと音質の予測（DNSMOS）で比べて、いちばんくずれにくい方法を選びました（くわしくは [scripts/audio/README.md](scripts/audio/README.md)）。
- **単語のボタンは、単語だけ**を読みます（文やフレーズにしません）。フレーズは、となりの丸いボタン、例文は例文の下のボタンで読みます。
- 品詞で発音が変わる語も、単語だけを、その用法の発音で読みます（`record` 名詞 /ˈrekərd/・動詞 /rɪˈkɔːrd/、`live` 動詞 /lɪv/・形容詞 /laɪv/、`excuse` 動詞 /z/・名詞 /s/）。発音記号と強く読む位置も表示します。
- 音声は「1つの英語 × ふつう／ゆっくり」ごとに別々の MP3 にしてあり、ボタンはその1つだけを鳴らします。さらに、ボタンのとなりに出している英語と、音声の英語が同じかを確かめてから鳴らします（違うときは鳴らしません）。全単語のボタン 736個を自動で点検しています。
- iPhone ではマナーモードでも鳴るようにしています（Web Audio。対応していない古いブラウザでは、音声ファイルの再生 → 端末の読み上げの順に切り替えます）。AI音声を読み込めないときは、一度だけ知らせて端末の読み上げに切り替えます。
- 端末の読み上げでは、**アメリカ英語（en-US）の声を最優先**し、その中でも Premium・Enhanced・Natural など高品質な声を選びます。設定の「端末の読み上げ」で声・速さ・1語ずつ区切るかを変えられます。
- 端末の読み上げが使えない端末でも、AI音声はそのまま使えます。AI音声がない英語のボタンは無効にして「この端末では再生できません」と表示します。

## 単語データ

初期データは **105語（132用法）** です。

1. **手書きの単語リスト（Untitled_Notebook.pdf）の94語（111用法）**：資料の順に並べ、最初はこちらから出題します。
   資料にあった `take` `well` `pretty` `look` は見本の単語にすでにあるため、重ねて追加していません。
2. **見本の11語（21用法）**：`pretty`（かわいい／けっこう）、`well`（上手に／うーん・さて／井戸）、`light`（明かり／軽い）、`record`（記録／録音する）、`live`（住む／生の）、`run`（走る／経営する）、`get`（手に入れる／〜になる）、`break`（割る／休憩）、`take`（持っていく／時間がかかる）、`on`（くっついて）、`look`（目を向ける）。

前の版を使っていた場合も、学習記録はそのままで、資料の単語だけが追加されます（自分で削除した見本の単語は戻りません）。

### 手書きの単語リストの読み取り

推測で確定しないように、次のように扱いました。照合結果の一覧は `data/notebook/REPORT.md` にあります。

| 資料の表記 | 登録した内容 | 理由 |
| --- | --- | --- |
| fell | **要確認**（出題しない） | fall の過去形か、feel の書き間違いか判断できない |
| brighe | **要確認**（出題しない） | この綴りの英単語が辞書にない。bright のつもりか確認が必要 |
| every one / every thing | everyone / everything | 前後の代名詞（anything・nobody）と同じ仲間として1語で登録。2語のつもりなら編集してください |
| became / seems | become / seem | 元の形で登録し、例文で became / seems を使用 |
| Brush | brush | 大文字で始まっていただけと判断 |
| many（数）/ much（量） | many / much | メモの「数」「量」を、数えられる／数えられないの違いとして説明に反映 |
| would / should | **未確認**（出題する） | Oxford の該当項目を確認できず、文法解説サイトの情報だけで照合したため |

`w` が「vv」のように見える字（few・low・wrong・show など）は、同じ書き方が続いていることから w と読みました。

### 出典と確認状況

単語ごとに **確認状況・確認日・確認方法・出典リンク** を記録し、単語詳細画面で見られます。

- **手書きリストの単語**は、`scripts/build-notebook.mjs` で辞書データと自動照合しています。照合できない項目が1つでもあると、データを作らずに止まります。
  - 品詞・意味：[Princeton WordNet 3.1](https://wordnet.princeton.edu/) に、その品詞の語義があり、指定した説明文を含むか。照合した語義は単語ごとに記録しています。WordNet にない代名詞・助動詞などは、Web 検索で表示された辞書の該当ページで照合し、その出典を記録しています。
  - 米音の発音記号：[CMU Pronouncing Dictionary](http://www.speech.cs.cmu.edu/cgi-bin/cmudict) の発音と、音の並びが一致するか（表記は Oxford 式にそろえています）。英音の発音記号は辞書と照合していません。
- **見本の11語**の品詞・意味・発音記号は、Web 検索で表示された辞書の該当ページ（Oxford Learner's Dictionaries、Merriam-Webster、Dictionary.com、語源は Online Etymology Dictionary など）の情報と照らし合わせて確認しました。
- 確認日はどちらも 2026-11-04 です。作成時の環境からは辞書サイトの本文を直接開けなかったため、その旨を確認方法に書いています。気になる点は、詳細画面の出典リンクや「辞書で調べる」リンクから確認できます。
- 例文・一言ニュアンス・場面の説明は、このアプリ用に作った学習用の文章です。

確認状況は3つです。

| 状態 | 意味 | 出題 |
| --- | --- | --- |
| 確認済み | 辞書などで確かめた（出典が必要） | する |
| 未確認 | 自分で入力したなど、まだ辞書で確かめていない | する（「未確認」と表示） |
| 要確認 | 読めない文字・英字以外の見出し語・意味が空など、不明な点がある | **しない** |

追加・読み込みのとき、見出し語に読めない文字（`�`）や英字以外の文字がある、意味が登録されていない、などの単語は、推測で直さずに自動で「要確認」にして理由を残します。

### 例文の書き方

例文の中のその用法の単語を `[ ]` で囲みます（例：`I'm [pretty] tired.`）。
裏面では強調表示、「場面 → 英語」では空欄になり、読み上げでは `[ ]` を外します。

- `pos`：`noun` `verb` `adjective` `adverb` `preposition` `interjection` `conjunction` `pronoun` `other`

## テスト

```sh
npm test          # 単体テスト（間隔反復・再出題・ポイント・連続日数・データ検証・保存・テストの採点・覚えていないリスト・音声・テストの時間割・カレンダー）
npm run test:e2e  # ブラウザでの操作テスト（Playwright + Chromium）
npm run build     # dist/core-image-cards.html を作り直す
npm run notebook  # 手書きリストのデータ（data/notebook/words-*.mjs）を辞書と照合して js/data-notebook.js を作り直す
```

`npm run notebook` を使うときは、先に `npm install` で辞書データ（cmu-pronouncing-dictionary・wordnet-db）を入れてください。アプリを動かすだけなら不要です。

E2E テストでは次のことを、実際のブラウザで操作して確かめています。

- カードの表裏切り替えと、裏面の表示順
- 単語・ゆっくり・フレーズ・例文の AI音声（その英語の区間を鳴らすこと・ゆっくりが長いこと・英語だけ・音声ボタンではカードが裏返らない）
- 実際のブラウザで AI音声のファイルを読み込み、最後まで鳴らせること。続けて押すと前の音が止まること
- AI音声がない英語は端末の読み上げ（ゆっくりは1語ずつ）
- 品詞で発音が変わる語の読み上げ（record・live・excuse）
- 端末の読み上げが使えない端末での表示（AI音声は使える・ない英語は無効と案内）
- 自己評価に応じた再出題、復習予定、翌日の復習優先
- ポイント・目標・連続日数
- 途中終了からの再開、履歴の保存と復元
- 単語の追加・編集・削除、要確認の除外
- 書き出し・読み込み、音声設定の保存、自動読み上げ、録音音声の表示
- ゆっくり再生で文を1語ずつ区切って読むこと
- 回のテスト：採点（66点 → 満点まであと34点）、途中で再読み込みしての再開、間違えた問題の一覧、覚えていないリストへの蓄積、練習では克服にならないこと、次の日の再テスト（間違えたときと同じ形式）での「克服」、2回目で満点を取ったときの表示と記録
- タイトル（暗記CARD）→ タップでホーム。セクションと ①〜⑤ の順番、いまの手順だけ青いボタン
- 毎日の順番（時計を進めて確かめる）：① → 結果画面から ② → ③ ミスを確認 → ④ 練習 → 20:00 前は ⑤ を受けられない → 20:00 にお知らせ → 今日のテスト → 次の日のタイトルに再テスト → 再テストで1問まちがえる → その次の日も → 満点で終わり
- テストの選択肢をタップした瞬間に、その選択肢の単語の音（その用法の AI音声）が鳴ること。答えたあとのタップ、正解のあと鳴り終わってから次へ進むこと
- まとめテスト（5日目の 20:00 から・応用の形式・1語から2問）と月のまとめテスト（12/1 の 20:00 から・11月の単語・30問）
- テストの時間の変更、カレンダー（.ics）の中身（3つの予定・毎日／5日ごと／毎月1日・その時刻に通知）、Googleカレンダーのリンク
- ホーム画面に追加：手順の画面・リンクのコピー、iPhone の Safari でだけホームに案内を出すこと（閉じたら出さない）、ホーム画面から開いたときの表示
- 記録を移す：claude.ai 版の「新しいアプリに移る」でコピーした記録を、新しいアプリの「記録を移す」に貼り付けて読み込めること（学習記録・使いはじめた日）
- GitHub Pages のように `/20260825_cctest/` の下に置いても、アイコン・オフライン用の仕組み・AI音声がそのまま動くこと
- 回ごとのカード学習（第1回のカードだけが出ること）
- 360px 幅での横スクロールなし
- 古い形のボタンが残っていないこと・青いボタンがまとまりごとに1つだけであること
- ホーム画面に追加の手順と、アイコン・全画面表示の設定（manifest）

端末の読み上げは端末ごとに声が違うため、E2E テストでは「英語の声がある端末」「声がない端末」「読み上げ非対応のブラウザ」をまねています。AI音声は、鳴らした区間を記録して、目録の区間と一致するかを確かめています。
